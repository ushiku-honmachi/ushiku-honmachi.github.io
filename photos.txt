# 写真の載せ方: 「グループ | ファイル名 | 説明 | English(なくてもOK)」を1行ずつ。
# グループは、次から選びます: 写真ニュース (「行事結果」の一番上に大きく出る。同じ名前のPDFが、タップで開く) /  区民会館 (「区民会館の写真・地図」に出る) / 行事 (「行事の写真」に出る)
# 写真のファイルは、このファイル(photos.txt)と同じ場所にアップロードしておきます。
# ファイル名は、半角の英数字だけにしてください。例: kumin-kaikan.jpg  bbq-2025.jpg
# 写真を1枚ずつ小さく(横1200ピクセルほど)しておくと、スマホでも速く開きます。
# 行の先頭の # を付けると、表示されなくなります。
#
# グループに「トップ」を選ぶと、ホームページの一番上で、写真が4秒ごとに入れ替わります(2〜4枚がおすすめ。横長の写真がきれいです)。
#   トップ | top1.jpg | 説明(なくてもOK)
#
